# Pyodide

Pyodide is a port of CPython to WebAssembly/Emscripten.

It compiles the entire CPython stack, and libraries like NumPy, into JavaScript and WASM.

It mostly just works with pure-Python packages!

:::{note} Why use Pyodide?
:label: note:why-pyodide
Deploying Python to the web makes it easier for people to use:

- No installation
- No expensive centralised compute resources
  :::
